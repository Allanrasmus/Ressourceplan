# Instruktioner til Codex
Svar på dansk. Udvikl et makrofrit Excel-værktøj (.xlsx) til fælles ressourceplanlægning i Teams/SharePoint. Brug Python og openpyxl som udgangspunkt; behold en reproducerbar build- eller migrationskode og automatiske tests i repository. Undersøg eksisterende workbook og HTML før ændringer. Brug kun fiktive data. Ingen eksterne forbindelser, VBA eller krav om Python hos slutbrugeren. Bevar originalfiler og indtastede data; skriv nye versionsfiler. Foretag små verificerbare ændringer, dokumenter begrænsninger og rapporter faktiske testresultater. Undgå at påstå at Excel Desktop/Online er testet, hvis det ikke er tilfældet. Kontrollér OOXML, formler, valideringer, filtre og beregningslogik. Se Projektkrav.md, DESIGN.md og TESTPLAN.md. Prioritér stabilitet og direkte indtastning frem for kosmetik. Foretag ikke ændringer i hovedbranch uden brugerens godkendelse.
